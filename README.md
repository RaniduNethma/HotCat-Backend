# HotCat - Backend

Smart Orders, Happier Tables.

Welcome to the backend of the HotCat project!

## What is HotCat?

HotCat is a restaurant management web application designed to streamline dining experiences. Built with a Node.js & Express backend powered by a **GraphQL API (Apollo Server)**, React frontend, and PostgreSQL database, it enables smart order handling, menu management, real-time order tracking via subscriptions, and efficient customer–restaurant interactions. The goal is to deliver a seamless, tech-powered dining experience.

## Prerequisites

Before you can start using this project, make sure you have the following installed on your local machine:

- Node.js
- npm
- PostgreSQL
- Redis

## Getting Started

Follow these steps to get started with the HotCat backend:

1. Clone this repository to your local machine:

   ```bash
   git clone https://github.com/RaniduNethma/HotCat-Backend.git
   cd HotCat-Backend
   ```

2. Install the dependencies:

   ```bash
   npm install
   ```

3. Copy `.env.example` file as `.env`:

   ```bash
   cp .env.example .env  #For Linux and macOS
   ```

4. Replace the environment variables in the newly created `.env` file with your configurations.

5. Run database migrations:

   ```bash
   npx prisma migrate deploy
   ```

6. Start the development server:

   ```bash
   npm run start:dev
   ```

7. Run Tests:

   ```bash
   npm test
   ```

8. Build for production:

   ```bash
   npm run build
   npm start
   ```

9. Open your browser and navigate to `http://localhost:${SERVER_PORT}/graphql` to access the GraphQL playground.

## Tech Stack

| Layer         | Technology                           |
| ------------- | ------------------------------------ |
| Runtime       | Node.js                              |
| Framework     | Express 5                            |
| API           | GraphQL (Apollo Server 5)            |
| Real-time     | WebSockets (`graphql-ws`), Socket.IO |
| ORM           | Prisma 7 (with `@prisma/adapter-pg`) |
| Database      | PostgreSQL                           |
| Caching       | Redis (ioredis)                      |
| Auth          | JWT (jsonwebtoken), bcrypt           |
| Validation    | Zod                                  |
| Data Batching | DataLoader                           |
| Language      | TypeScript                           |
| Testing       | Jest                                 |
